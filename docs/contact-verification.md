# Public enquiry and photo verification

The public `/contact` form sends one transactional notification to `info@dmpaintingdecorating.co.uk`, with the enquirer's address as Reply-To. `RESEND_API_KEY` and `DM_CONTACT_FROM_EMAIL` must exist in each intended Vercel environment. The key stays server-side. The sender must belong to a verified sending domain in the account owning that key.

Original photos may total 15 MB, with up to six files of 5 MB each. The browser resizes large supported photos before upload so the whole multipart request stays below Vercel's 4.5 MB request limit. Browsers unable to decode a large HEIC photo show a useful error and the direct email alternative. The server permits a maximum of 4 MB of photo bytes and checks image signatures, required fields and consent before calling Resend. Attachment extensions and MIME types are derived from image signatures, so an uploaded HTML filename cannot select an active attachment type. An enquiry retry keeps its idempotency key and does not intentionally send a second notification. Requests to Resend time out after 15 seconds; the form clears customer details only after an explicit successful response.

`tests/contact/route.test.ts` checks server validation, attachment byte preservation, HTML escaping, idempotency and provider failures using a fake provider. `tests/e2e/contact.spec.ts` checks the public form on desktop and mobile Chromium, including the actual browser image resize, encoded multipart payload and retry behavior, with the public endpoint intercepted. Neither suite proves live delivery.

Before release, verify the deployed preview has both environment variable names and a verified sender. Send a clearly labelled TEST ONLY enquiry with a small photo from the real public form. Locate that exact notification in the correct Resend account, confirm delivered status, check the recipient and Reply-To, and inspect the attached photo. Record the test timestamp and email ID privately. Do not mark notifications verified merely because the page displays its success message.
